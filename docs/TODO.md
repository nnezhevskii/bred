# Bred — очередь задач

Открытые задачи расположены по критичности сверху вниз. Приоритет учитывает последствия для файлов, результата программы и процесса сборки. Внутри уровня выше стоят задачи с более прямым влиянием. G-ID постоянны.

На 12 ноября 2026 года три падения JVM-тестов воспроизведены в G-74. Остальные находки ревизии основаны на чтении кода. Для короткой первой сессии подойдёт G-74 или G-57. [Ревизия с исходными данными](AUDIT.md) · [Маршрут возвращения](RETURNING.md)

Подробная очередь по границе АСД → 3AC содержит 17 задач с примерами воспроизведения и критичностью. [TODO по контракту](AST_TAC_TODO.md)
